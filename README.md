PhishGuard is a browser extension designed to provide real-time protection against phishing attacks through a dual-layered detection mechanism combining blacklist lookup and machine learning (ML) classification. This report presents the research, design, development, and evaluation of the PhishGuard prototype, targeting Google Chrome as the initial deployment platform.
Phishing remains the dominant vector for cybercrime globally. In 2025, over 3.8 million phishing attacks were recorded, and the average cost of a phishing-related data breach reached $4.88 million (IBM, 2025). Despite widespread awareness, automated, client-side mitigation tools remain underutilised. PhishGuard addresses this gap by scanning URLs in real time, querying the PhishTank API for blacklist matches, and invoking an ML model trained on URL-based features to flag zero-day threats not yet captured in blacklists. The solution is lightweight, privacy-preserving, and designed for non-technical users. This report concludes with an evaluation of the prototype, key findings, and recommendations for future development.
